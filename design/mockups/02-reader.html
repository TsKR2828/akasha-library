SEO Pipeline 六步流程筆記

seo-pipeline-notes.md · 最後編輯 2026-07-05 · 3,412 字 · ≈ 9 分鐘

Step 1 — 關鍵字叢集

先把主題拆成叢集，每個叢集對應一個 pillar page 加上若干支撐文章。叢集之間的內鏈結構決定了權重的流向，寧可叢集小而深，不要大而淺。

↳ 圖書館員眉批：這一段可以直接餵給 Table Forge 抽成表格

Step 2 — 抓取與解析

解析器的核心邏輯如下，注意 fallback 鏈的順序：

# 程式碼 = 舊紙標本，左邊一道分區墨色 def parse_serp(html, *, depth=3): tree = extract(html) or fallback(html) return [Cluster('pillar', c) for c in tree]

Step 3 — 內容生成

產出走 Charta 筆記本區塊系統：margin-note 放田野觀察、tangent 放離題補充。發佈前一律過人工審稿，AI 只負責初稿與結構。
