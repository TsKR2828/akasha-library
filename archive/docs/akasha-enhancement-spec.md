## 1. 模組總覽與資料流

### 1.1 四個模組定位

| 模組 | 代號 | 定位 |
|------|------|------|
| PDF Reader | Reading Hall | 閱讀 PDF、切割、OCR、書籤、AI 伴讀 |
| Code & Data | Manuscripta | 閱讀與編輯程式碼 / 資料檔（.py .json .md .txt .score.json） |
| Table Forge | Tabularium | 表格操作：排序、篩選、批次編輯、匯出 |
| Script Editor | （獨立專案） | 劇本卡片編輯、角色資料卡、AVG JSON 輸出 |

### 1.2 模組間資料流

```
PDF Reader ──→ 個人書庫 ──→ Script Editor
  │ OCR 文字                    ↑ 匯入素材
  │ 截圖框選（便條紙）            │
  ↓                             │
個人書庫 ←──────────────────────┘
  ↑                             ↑
  │ 存檔                        │ 存檔
  │                             │
Code & Data ──→ Table Forge ──→ 個人書庫
  │ JSON/MD 表格    ↑ blocks→table
  │ 自動偵測         │ batch edit→blocks
  ↓                 ↓
Table Forge ←── Script Editor
```

### 1.3 資料流規則

- 所有模組的存檔統一進個人書庫（IndexedDB + Google Drive 同步）
- 模組之間傳遞資料使用 PostMessage API 或書庫中轉
- 不需要經過本機下載再上傳
- 匯出到外部（下載檔案）在版權邊界章節另行規範

## 2. App Shell 層級修正

### 2.1 Header 統一

所有模組的 header 統一為兩層結構：

**第一層（固定高度，所有模組一致）：**
- 左側：麵包屑 `AKASHA LIBRARY > TOOLS > 模組名`
- 右側：「召喚圖書館員」按鈕（金色，見第 3 章）

**第二層（各模組自有工具列，高度可不同）：**
- PDF Reader：PAGES / CUT / LIB tab + 縮放 + 開啟
- Code & Data：按鈕群（開啟檔案、編輯模式、複製、匯出等）
- Table Forge：匯入 / 匯出 / 刪除
- Script Editor：（預留）

### 2.2 右上角區域修正

**現況問題：**
- 右上角的功能區目前綁定 Code & Data，在其他模組內按會跳回 Code & Data
- 目前已隱藏但未修復

**修正方案：**
- 右上角區域提升到 App Shell 層級，不屬於任何單一模組
- 固定放置：「召喚圖書館員」按鈕
- 其他功能按鈕（如「+ 新建」「匯入」）下放到各模組自己的第二層工具列
- 確保在任何模組內點擊右上角功能，不會跳轉到其他模組

### 2.3 側欄（Sidebar）

維持現有結構不變：

```
I  NAVIGATE
   總覽 OVERVIEW
   個人書庫 MY LIBRARY
   公共書庫 PUBLIC STACKS

II TOOLS
   Code & Data  MANUSCRIPTA
   PDF 閱讀器   READING HALL
   Table Forge  TABULARIUM
   書籍排版器   BINDERY
   AI 設定      AETHERIUM
```

Script Editor 上線後加入 TOOLS 區塊：
```
   Script Editor  （待定代號）
```

### 2.4 HINTS 聯動系統

適用模組：Code & Data、Table Forge（PDF Reader 無側欄 HINTS，不適用）。

HINTS 區塊分為上下兩段，以細分隔線區隔：

**上半段（固定）——檔案格式說明：**
- 永遠顯示當前檔案的格式說明，不受任何操作影響
- 內容依檔案類型切換（見 `code-data-reader-spec.md` 的 HINTS 規則）
- 使用者隨時往左邊看，格式說明永遠在那裡

**下半段（動態）——操作紀錄 + 按鈕說明：**

此區域有兩層資訊，依優先順序顯示：

第一層：上一步操作紀錄（持久）
- 每次使用者執行操作（複製、下載、匯出等），在此顯示操作結果
- 帶 ✓ 標記和相對時間戳
- 不會自動消失，直到下一次操作才被新的取代
- 使用者離開又回來仍可看到「上次做了什麼」

第二層：當前 hover 按鈕說明（即時）
- 滑鼠移到工具列按鈕時，在操作紀錄下方即時顯示該按鈕的白話說明
- 滑鼠移開後消失，僅保留操作紀錄

兩層同時顯示範例：

```
HINTS
─────────────────────────────────
.json — JSON 資料格式
可用「Pretty JSON」看排版後的版本，
或用「樹狀 JSON」展開結構。
編輯時會自動檢查格式是否正確。
─────────────────────────────────
✓ 已複製原始內容（3 秒前）
▸ 複製目前視圖
  複製畫面上看到的樣子，符號會變成標題粗體等
```

僅有操作紀錄、無 hover 時：

```
HINTS
─────────────────────────────────
.json — JSON 資料格式
（格式說明略）
─────────────────────────────────
✓ 已複製原始內容（2 分鐘前）
```

初始狀態（無操作、無 hover）：

```
HINTS
─────────────────────────────────
.json — JSON 資料格式
（格式說明略）
─────────────────────────────────
```

下半段為空白，不顯示佔位文字。

### 2.5 提示機制（跨平台）

**桌面版：**
- 工具列按鈕 hover → HINTS 下半段即時顯示說明（見 2.4）
- 操作完成 → HINTS 下半段顯示操作結果紀錄（見 2.4）
- 操作完成 → 工具列旁同時出現 toast 提示（如「已複製原始內容」），2～3 秒後淡出

**手機版：**
- 長按（long press）工具列按鈕 → 彈出 popover 氣泡顯示按鈕說明
- 放開後 popover 消失
- 操作完成 → toast 提示（同桌面版）
- 手機版無側欄 HINTS（側欄預設收合），以 popover 取代

**首次使用引導（可選）：**
- 第一次進入模組時，可跑一次 onboarding 引導
- 半透明遮罩依序高亮每個按鈕，旁邊顯示一句說明
- 點任意處跳下一個，跑完後不再出現
- 使用者可在設定中重新觸發
- 此功能為可選項，不阻擋第一版上線

## 3. 零韻面板（跨模組 AI 圖書館員）

### 3.1 面板定位

零韻（月上零韻 / Tsukigami Reiin）是阿卡夏圖書館的 AI 圖書館員，提供文字與語音伴讀、內容問答、輔助建議。

### 3.2 入口

- 「召喚圖書館員」按鈕位於 App Shell 第一層 header 右側（所有模組共用）
- 點擊後右側滑出零韻面板
- 面板可收合，收合狀態按模組獨立記憶（localStorage）
- 收合 icon：眼睛 toggle（沿用 PDF Reader 現有設計）

### 3.3 面板 UI

沿用 PDF Reader 現有設計：

| 區塊 | 內容 |
|------|------|
| 頂部 | 狀態指示燈（BIBLIOTHECARIA 在線）+ 收合/關閉按鈕 |
| Tab | 文字 / 語音 / 人設 |
| 立繪區 | Live2D 或靜態立繪，可顯示/隱藏 |
| 對話區 | 打字機效果 + 情緒標籤 |
| 底部 | 月幣餘額 + token 預估 + 輸入框 |

### 3.4 跨模組 Context 切換

面板元件為同一個，根據當前所在模組自動切換 context：

| 模組 | 零韻角色 | 背後引擎 | 可調用資料 |
|------|---------|---------|-----------|
| PDF Reader | 圖書館員 | RAG（BM25 + Dense）+ Claude API | 當前開啟的 PDF 內容 |
| Code & Data | 手稿解讀員 | Claude API | 當前開啟的檔案內容 |
| Table Forge | 資料檢查員 | Claude API | 當前表格資料 |
| Script Editor | 劇本顧問 | RAG（Drama Text Archive）+ Claude API | 角色資料庫 + TAG 字典 |

### 3.5 人設管理

- 核心人設檔案：`persona.md`（一份，所有模組共用）
- 場景描述欄位：根據模組動態注入不同的 `context` 段落
- 人格、口吻、情緒表達方式在所有模組保持一致
- 差異僅在於「她知道自己現在在哪個工作台」以及「她能調用什麼工具」

### 3.6 對話紀錄

- 每個模組獨立維護對話紀錄，切換模組時對話不混在一起
- 所有模組的歷史對話統一存入個人書庫，可在書庫內回顧
- 單一模組內的對話紀錄隨 session 存在，關閉模組後仍保留在書庫

### 3.7 計費

- 統一使用月幣系統
- Claude API 呼叫：按 token 數計費
- OCR 掃描：每頁 1～5 月幣（見第 4 章）
- RAG 檢索 + LLM 回覆：按實際 token 消耗計
- 備選：BYOK（Bring Your Own Key）模式，使用者自帶 API key

### 3.8 後台資料庫（預寫回應）

- 用途：常見問候、功能說明、操作提示，不需要每次打 API
- 按模組分 collection，每個模組有自己的常見問答
- 格式：JSON，key = 觸發意圖，value = 零韻的預寫回應
- 優先匹配預寫回應，無匹配時才打 Claude API

## 4. PDF Reader 補強

### 4.1 現有功能（不重複列出）

參見原始功能清單：閱讀、載入、切割、匯出、書庫、AI 面板、UI。

### 4.2 新增：OCR 文字摘錄

| 功能 | 說明 |
|------|------|
| 單頁 OCR | 對當前頁面執行 OCR，提取文字 |
| 計費 | 每頁 1～5 月幣 |
| 結果儲存 | OCR 出的文字存入個人書庫的筆記區，與原始 PDF 建立關聯 |
| 禁止複製到外部 | OCR 結果不可複製到剪貼簿、不可下載為文字檔 |
| 警示文案 | 嘗試帶出時顯示：「可以做筆記，為保護智慧財產權，不可以帶出館藏喔」 |
| 無「匯出全文」按鈕 | 不提供全書 OCR 匯出功能 |

### 4.3 新增：截圖框選

| 功能 | 說明 |
|------|------|
| 框選工具 | 使用者在 PDF 頁面上拖拉框選一個區域 |
| 便條紙樣式 | 框選結果以便條紙視覺呈現（外框、紙張質感） |
| 存入書庫 | 截圖筆記存入個人書庫，與原始 PDF 和頁碼建立關聯 |
| 送到 Script Editor | 截圖筆記可透過 PostMessage 或書庫中轉送到 Script Editor 當素材 |
| 技術實作 | Canvas 截圖（`toDataURL`），不抽取 PDF 內嵌圖片 |

### 4.4 新增：書籤功能

| 功能 | 說明 |
|------|------|
| 新增書籤 | 在當前頁面標記書籤，可選填備註文字 |
| 書籤列表 | 側欄（LIB tab 或新增 BOOKMARK tab）顯示所有書籤，點擊跳頁 |
| 書籤排序 | 按頁碼排序 |
| 刪除書籤 | 可刪除單一書籤 |
| 書籤持久化 | 書籤資料存入 IndexedDB，與該 PDF 的書庫條目關聯 |
| 書籤同步 | 隨書庫同步到 Google Drive |

### 4.5 自訂選擇切割

| 功能 | 說明 |
|------|------|
| 現況 | UI 有 placeholder 但邏輯未實作 |
| 決策 | 補完實作，或移除 placeholder。不可留著讓使用者以為是 bug |
| 建議 | 補完——讓使用者勾選要切出的頁面，點切割後下載或存入書庫 |

## 6. Table Forge 補強

### 6.1 零韻面板接入

- 接入 App Shell 層級的零韻面板（見第 3 章）
- Context：資料檢查員
- 背後引擎：Claude API
- 可調用資料：當前表格資料
- 使用場景（限劇本資料情境）：
  - 批次檢查空欄位（「這五句台詞沒有情緒 TAG」）
  - 資料一致性掃描（「角色 B 的立繪欄位全部是空的」）
  - 密度分析（「第三章的台詞密度特別低」）
- 通用表格不主動觸發零韻建議

### 6.2 從 Script Editor 接收資料（預留）

- 接收 Script Editor 的 dialogue blocks，攤成表格顯示
- 欄位對應：角色名稱 / 台詞 / 場景・章節 / 情緒 / 對應立繪
- 支援排序、篩選、批次修改
- 修改後寫回 Script Editor 的 blocks.jsonl
- 此功能於 Script Editor 上線後啟用

## 7. Script Editor 接口預留

> Script Editor 為獨立專案，本文件不定義其內部實作。
> 僅定義阿卡夏圖書館與 Script Editor 之間的接口。

### 7.1 資料輸入接口

| 來源 | 傳輸方式 | 資料格式 |
|------|---------|---------|
| PDF Reader（OCR 文字） | 書庫中轉 | 純文字 + 來源 PDF ID + 頁碼 |
| PDF Reader（截圖框選） | 書庫中轉 | 圖片 blob + 來源 PDF ID + 頁碼 |
| Code & Data（JSON） | PostMessage 或書庫中轉 | .json / .jsonl 檔案 |
| Table Forge（批次編輯結果） | PostMessage 或書庫中轉 | blocks.jsonl |

### 7.2 資料輸出接口

| 目的地 | 傳輸方式 | 資料格式 |
|--------|---------|---------|
| Table Forge | PostMessage 或書庫中轉 | dialogue blocks → 扁平表格 JSON |
| 個人書庫 | 直接寫入 IndexedDB | script.blocks.jsonl / export.avg.json |
| 外部匯出 | 下載 | AVG JSON / locked PDF / MD |

### 7.3 零韻面板接口

- 接入 App Shell 層級的零韻面板（見第 3 章）
- Context：劇本顧問
- 背後引擎：RAG（Drama Text Archive）+ Claude API
- 功能：
  - 角色口吻建議
  - 情緒 TAG / 劇情功能 TAG 推薦
  - 翻譯輔助
  - 糾錯（RAG 撈原作段落比對）
  - 章節紀錄查詢（查目錄 JSON，成本極低）

### 7.4 側欄登錄

Script Editor 上線後加入左側 sidebar TOOLS 區塊。

## 8. 書庫與資料流規則

### 8.1 個人書庫

| 項目 | 說明 |
|------|------|
| 儲存引擎 | IndexedDB |
| 同步 | Google Drive 雙向同步 |
| 離線模式 | 斷網時用本地 IndexedDB，恢復後自動同步 |
| 儲存內容 | PDF 檔案、程式碼/資料檔、OCR 筆記、截圖便條紙、書籤、表格、劇本草稿、零韻對話紀錄 |

### 8.2 存檔規則

- 所有模組的「存檔」動作統一寫入個人書庫
- 不需要經過本機下載再上傳
- 「下載到本機」是獨立的匯出動作，不等於存檔

### 8.3 跨模組開啟

- 書庫中的檔案可以從任何相容的模組開啟
- 例如：書庫裡的 .json 可以從 Code & Data 開啟，也可以送到 Table Forge
- 開啟時由檔案類型決定預設模組，使用者可手動選擇

## 9. 版權邊界

### 9.1 基本原則

- OCR 文字和截圖筆記可以在書庫內自由流動（模組間傳遞）
- 匯出到外部時檢查版權邊界
- 使用者自寫內容不受限制

### 9.2 各功能的版權處理

| 功能 | 是否可帶出書庫 | 說明 |
|------|--------------|------|
| OCR 文字 | ❌ | 鎖在書庫內，不可複製到剪貼簿、不可下載 |
| 截圖框選 | ❌ | 同上 |
| 使用者自寫筆記 | ✅ | 可匯出 |
| 使用者自寫劇本 | ✅ | 可匯出為 AVG JSON、MD 等 |
| 編輯後的程式碼 | ✅ | 可下載、可存書庫 |
| 匯出摘要（自動產生） | ✅ | 結構化摘要為衍生內容，可匯出 |
| 鎖死 PDF 匯出 | ✅ | 使用者自寫內容可輸出為不可複製文字的 PDF |

### 9.3 警示文案

當使用者嘗試將受版權保護的內容帶出書庫時，統一顯示：

> 可以做筆記，為保護智慧財產權，不可以帶出館藏喔

### 9.4 去浮水印

- 不納入阿卡夏圖書館系統
- 如有個人需求，以獨立本機腳本處理，不進產品

## 10. 名詞對照

供開發與文件撰寫參考，確保全系統用詞一致。

| 術語 | 白話解釋 |
|------|---------|
| 視圖（View） | 用什麼方式看檔案。同一個檔案可以有多種視圖 |
| 渲染（Render） | 把原始文字（如 `### 標題`）變成格式化畫面的過程 |
| Pretty Print | 把擠成一行的 JSON 重新排版加縮排，內容不變 |
| 原始碼（Raw / Source） | 檔案最原始的文字內容，沒有任何格式化處理 |
| 結構化摘要 | 程式自動從檔案中抽取結構，產生重點清單 |
| 書庫 | 阿卡夏圖書館的檔案儲存空間，存在這裡不需要每次從本機重新上傳 |
| OCR | 光學字元辨識，把圖片上的文字變成可搜尋的文字 |
| RAG | 檢索增強生成，先搜尋相關段落再餵給 AI 回答，不需要把整本書塞進去 |
| PostMessage | 瀏覽器內模組之間傳遞資料的 API |
| IndexedDB | 瀏覽器內建的本地資料庫，可存大量資料 |
| blocks.jsonl | Script Editor 的劇本草稿格式，每行一個對話/旁白/指令 block |
| AVG JSON | 視覺小說引擎讀取的劇本格式 |
| 月幣 | 阿卡夏圖書館的虛擬貨幣，用於 AI 功能計費 |
| BYOK | Bring Your Own Key，使用者自帶 API key 免花月幣 |
| persona.md | 零韻的人設指令檔，定義她的個性、口吻、回應風格 |
| context | 零韻在不同模組中的角色切換欄位 |
| App Shell | 所有模組共用的外殼（sidebar + header），不屬於任何單一模組 |
| HINTS 聯動 | 側欄 HINTS 區塊根據滑鼠 hover 的按鈕即時切換顯示對應說明 |
| Toast 提示 | 操作完成後短暫出現的通知（如「已複製原始內容」），幾秒後自動消失 |
| Popover | 長按按鈕時彈出的說明氣泡，手機版用來取代桌面的 hover 說明 |
| Onboarding 引導 | 首次使用時的功能導覽，半透明遮罩依序高亮按鈕並顯示說明 |
| 操作紀錄 | HINTS 下半段保留的上一步操作結果，幫助使用者回憶「剛剛做了什麼」 |
