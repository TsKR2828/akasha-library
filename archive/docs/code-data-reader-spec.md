# Code & Data Reader — 功能規格書

> 模組定位：阿卡夏圖書館（Akasha Library）內建工具，用於閱讀、編輯、匯出程式碼與資料檔案。
> 本文件為開發用 spec，所有功能以下方清單為準。

---

## 1. 檔案載入

| 功能 | 說明 |
|------|------|
| 開啟檔案 / 拖放 | 支援 `.py` `.json` `.score.json` `.md` `.txt` |
| PostMessage API | 從主殼（dashboard）接收檔案 |
| 草稿恢復 | localStorage 自動存，意外關閉時還原上次編輯內容 |

---

## 2. 多格式閱讀（視圖系統）

同一個檔案可以用不同「視圖」檢視。視圖 = 顯示同一份資料的不同方式。

| 視圖名稱 | 適用格式 | 說明 |
|----------|----------|------|
| Markdown 預覽 | `.md` | 將 `# 標題`、`**粗體**` 等 Markdown 語法渲染成格式化 HTML |
| Pretty JSON | `.json` | 將壓縮的 JSON 重新排版（加換行、縮排），方便人類閱讀。內容不變，只改排版 |
| 樹狀 JSON | `.json` | 可展開 / 收合的 JSON 樹狀結構 |
| Score View | `.score.json` | TsukiSynth 專用儀表板（素材、事件、匯出設定） |
| Python View | `.py` | 行號 + 語法高亮 + 左側摘要（imports / functions / classes / main guard） |
| 純文字閱讀 | `.txt` | 原文直接顯示。因為 .txt 沒有語法規則，所以「純文字閱讀」和「原始碼」看起來完全一樣，這是正常的 |
| 原始碼頁籤 | 全部格式 | 顯示檔案的原始文字（未經任何渲染的版本） |

## 3. 編輯

| 功能 | 說明 |
|------|------|
| 編輯模式 | `.md` `.txt` `.json` 可直接編輯，JSON 編輯時會即時驗證格式 |
| 存檔至書庫 | **【新增】** 編輯完直接存入阿卡夏圖書館書庫，不需經過本機 |
| 下載新檔 | 編輯後另存下載到本機 |
| 編輯歷史紀錄 | **【新增】** 記錄每次存檔的版本，可回溯查看過去版本 |
| Undo / Redo 按鈕 | **【新增】** 編輯中的返回 / 往後操作 |
| 變更標示 | **【新增】** 編輯後有變動的文字以 highlight 標示，方便確認改了哪裡 |
| 一鍵清除標示 | **【新增】** 確認變更無誤後，可一鍵取消所有 highlight |

## 5. 複製與匯出

| 功能 | 說明 |
|------|------|
| 複製原始內容 | 複製檔案的原始文字到剪貼簿（例如 `### 標題` 會維持 `###` 符號） |
| 複製目前視圖 | 複製渲染後畫面上看到的文字（例如 `### 標題` 會變成格式化的標題文字） |
| 下載目前內容 | 下載檔案到本機（JSON 自動 pretty print） |
| 匯出摘要 .md | 依檔案格式自動產生結構化摘要 Markdown（例如 Python → 列出 imports / functions / classes）。`.txt` 不適用此功能，按鈕應 disable 並顯示提示 |
| 摘要存入書庫 | **【新增】** 產生的摘要可直接存入阿卡夏圖書館書庫，與原始檔案建立關聯 |

## 10. Tooltip 與 HINTS 規則

### 10-1. 工具列按鈕 Tooltip

每個按鈕 hover 時顯示一行白話說明：

| 按鈕 | Tooltip 文字 |
|------|-------------|
| 開啟檔案 | 從電腦選一個檔案打開 |
| 編輯模式 | 直接修改檔案內容（支援 md / txt / json） |
| 複製原始內容 | 複製你實際打的文字，包含 `###` 這些符號 |
| 複製目前視圖 | 複製畫面上看到的樣子，符號會變成標題粗體等 |
| 下載目前內容 | 把檔案存到你的電腦 |
| 匯出摘要 .md | 自動幫你整理這個檔案的重點大綱 |
| 存檔至書庫 | 把編輯後的檔案存進圖書館，下次不用重新上傳 |
| 送到 Table Forge | 把內容傳到表格工具做進一步處理 |
| 搜尋 | 在檔案中搜尋關鍵字 |

### 10-2. HINTS 區塊內容規則

根據載入的檔案格式，HINTS 應顯示：
1. 這是什麼格式（一句話）
2. 這個格式能做什麼 / 不能做什麼
3. 可能讓人困惑的行為預先解釋

範例：

**`.txt`**
> 純文字檔，可以直接編輯。「文字閱讀」和「原始碼」看到的內容會一樣，這是正常的！匯出摘要不適用這個格式。

**`.md`**
> Markdown 格式，支援標題、粗體、表格等語法。切換「Markdown 預覽」可看到渲染後的效果，「原始碼」可看到原始語法。

**`.json`**
> JSON 資料格式。可用「Pretty JSON」看排版後的版本，或用「樹狀 JSON」展開結構。編輯時會自動檢查格式是否正確。

**`.py`**
> Python 程式碼。左側摘要會自動列出 imports、functions、classes。系統會掃描是否有刪檔、連網等風險操作。

**`.score.json`**
> TsukiSynth 評分檔案，使用專用儀表板顯示素材、事件與匯出設定。

## 附註：名詞對照

供開發與文件撰寫參考，確保全系統用詞一致。

| 術語 | 白話解釋 |
|------|---------|
| 視圖（View） | 用什麼方式看檔案。同一個檔案可以有多種視圖 |
| 渲染（Render） | 把原始文字（如 `### 標題`）變成格式化畫面（如大字粗體標題）的過程 |
| Pretty Print | 把擠成一行的 JSON 重新排版加縮排，內容不變，只改排版 |
| 原始碼（Raw/Source） | 檔案最原始的文字內容，沒有任何格式化處理 |
| 結構化摘要 | 程式自動從檔案中抽取結構（如標題大綱、函式列表），產生一份整理好的重點清單 |
| 書庫 | 阿卡夏圖書館的檔案儲存空間，存在這裡的檔案不需要每次從本機重新上傳 |
